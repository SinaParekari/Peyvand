## معرفی پروژه

**PEYVAND (پیوند)** یک سامانه تحت وب برای مدیریت شبکه و فعالیت‌های فروش در کسب‌وکارهای مبتنی بر بازاریابی شبکه‌ای (MLM) است.

این سامانه با هدف ساده‌سازی و یکپارچه‌سازی فرایندهای مدیریتی و عملیاتی کسب‌وکارهای شبکه‌ای طراحی شده است. مدیران از طریق یک محیط متمرکز می‌توانند اعضا را مدیریت کنند، روابط سازمانی و ساختار شبکه را زیر نظر بگیرند، فعالیت‌های فروش را پیگیری کنند، پورسانت‌ها را محاسبه کنند و سوابق پرداخت را مدیریت نمایند.

پیوند از مدل ارسال مستقیم کالا توسط شرکت (Company-Direct Fulfillment) استفاده می‌کند. در این مدل، اعضا مشتریان را جذب کرده و سفارش‌های آن‌ها را در سامانه ثبت می‌کنند؛ سپس شرکت مسئولیت آماده‌سازی، پردازش و ارسال مستقیم سفارش به مشتری را بر عهده می‌گیرد.

تمرکز اصلی پیوند بر ایجاد زیرساخت مدیریتی موردنیاز برای یک کسب‌وکار مبتنی بر فروش شبکه‌ای است، نه ایجاد یک فروشگاه اینترنتی سنتی.

## مدل کسب‌وکار

پیوند بر اساس مدل **ارسال مستقیم کالا توسط شرکت (Company-Direct Fulfillment / Drop Shipping)** طراحی شده است.

فرایند فعالیت سامانه به شکل زیر است:

1. عضو به شبکه ملحق می‌شود و یک کد معرفی و لینک اختصاصی دریافت می‌کند.
2. عضو از طریق فعالیت‌های بازاریابی خود، مشتریان بالقوه را به خرید محصولات شرکت ترغیب می‌کند.
3. عضو سفارش مشتری را از طریق پنل اختصاصی خود در سامانه ثبت می‌کند.
4. شرکت مسئولیت آماده‌سازی، پردازش و ارسال مستقیم محصول به مشتری را بر عهده می‌گیرد.
5. سامانه سفارش ثبت‌شده را به عضو مسئول جذب مشتری منتسب می‌کند.
6. موتور محاسبه پورسانت، سود یا پورسانت مربوط به عضو را بر اساس قوانین تعریف‌شده محاسبه می‌کند.
7. نتیجه محاسبه در سامانه ثبت می‌شود و وضعیت پرداخت آن توسط مدیریت قابل پیگیری خواهد بود.

در این مدل، اعضا نیازی به نگهداری موجودی شخصی محصولات ندارند و تمام عملیات آماده‌سازی و ارسال سفارش توسط شرکت انجام می‌شود.

## معماری پروژه

پیوند بر اساس معماری یک برنامه وب مبتنی بر Django و رندر سمت سرور (Server-Side Rendering) طراحی شده است.

- **Django:** مدیریت منطق کسب‌وکار، احراز هویت، عملیات پایگاه داده، پردازش درخواست‌ها و تولید صفحات سمت سرور.
- **HTML:** ایجاد ساختار صفحات وب.
- **Tailwind CSS:** طراحی رابط کاربری، استایل‌دهی و ایجاد چیدمان واکنش‌گرا.
- **Alpine.js:** پیاده‌سازی تعاملات سبک و پویا در سمت کاربر.
- **PostgreSQL:** ذخیره‌سازی و مدیریت داده‌های رابطه‌ای سامانه.

در این معماری، رابط کاربری مستقیماً با صفحات تولیدشده توسط Django کار می‌کند و برای اجرای بخش فرانت‌اند نیازی به ایجاد یک برنامه مستقل و جداگانه نیست.

مراحل نصب، پیکربندی محیط توسعه، راه‌اندازی پایگاه داده و اجرای پروژه هم‌زمان با پیشرفت فرایند پیاده‌سازی تکمیل و مستندسازی خواهند شد.

### پیش‌نیازها

- Git
- PostgreSQL

### نصب و اجرا

ابتدا مخزن پروژه را دریافت کنید:

```bash
git clone https://github.com/YOUR_USERNAME/peyvand.git
cd peyvand
```

یک محیط مجازی ایجاد کنید:

```bash
python -m venv .venv
```

محیط مجازی را فعال کنید.

در ویندوز:

```bash
.venv\Scripts\activate
```

در لینوکس و macOS:

```bash
source .venv/bin/activate
```

وابستگی‌های پروژه را نصب کنید:

```bash
pip install -r requirements.txt
```

فایل تنظیمات محیط را بر اساس نمونه ارائه‌شده در پروژه ایجاد و تنظیمات پایگاه داده را پیکربندی کنید.

سپس Migrationهای پایگاه داده را اجرا کنید:

```bash
python manage.py migrate
```

در نهایت سرور توسعه را اجرا کنید:

```bash
python manage.py runserver
```

**توجه:** دستورات بالا مراحل اولیه راه‌اندازی یک پروژه Django هستند. جزئیات متغیرهای محیطی، تنظیمات پایگاه داده و سایر پیش‌نیازهای اجرایی هم‌زمان با تکمیل پیاده‌سازی مستند خواهند شد.
